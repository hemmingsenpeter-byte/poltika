# IP doctrine

Poltika respects the boundary between reference and source.

## Rule

External implementations, including OpenFisca, are not permitted to function as the authoritative source for NZ policy rules.

## Allowed usage

- Structural inspiration
- Pattern review
- Compatibility checks

## Disallowed usage

- Copying statutory logic without evidence
- Treating external implementations as legal truth
- Using external code as the source of policy interpretation

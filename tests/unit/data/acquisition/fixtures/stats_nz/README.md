# Synthetic Stats NZ fixtures

SYNTHETIC. These files are invented to exercise the connector's parsing. They
are not Stats NZ responses, not real snapshots, and carry no real statistics.
The shapes follow the SDMX 2.1 structure message that the public ADE catalogue
endpoint returns (https://api.data.stats.govt.nz/rest/dataflow/STATSNZ/all?detail=allstubs).
The dataflow id `TST_TST_001` does not exist.

Introduction

Below are the four areas used for the calculation of Accommodation Supplement from 1 April 2018. The locations within each area are sorted alphabetically.

The locations listed below relate specifically to the names of the Statistical Area Units 2017, as defined by Statistics New Zealand. They are not equivalent to postal address suburbs, towns or cities, despite occasionally sharing similar names.

To confirm an area code for a specific address, use CMS or the Accommodation Supplement area map [no link find out why] tool.

If an address has not been validated, contact Helpline to get an area code assigned manually. StudyLink and Contact Centre staff can ask their manager to do this. The address validation checks and CMS notes must be completed before an Accommodation Supplement area code can be assigned.
